# Ajuste: menu hamburguer com rolagem no celular

Foi aplicado um ajuste no CSS do cabeçalho para que, no modo celular, ao abrir o menu hamburguer:

- O menu ocupe a tela inteira.
- A lista de opções possa ser rolada com o dedo.
- O cabeçalho fique fixo no topo enquanto os links rolam.
- Os botões do menu fiquem maiores e mais fáceis de tocar.

Arquivo alterado:

- `static/css/app.css`
