# Ícone do aplicativo alterado para o Solzinho

Atualizei os ícones usados quando o sistema é instalado no celular como PWA.

Arquivos alterados:

- `static/img/pwa-192.png`
- `static/img/pwa-512.png`
- `static/img/apple-touch-icon.png`
- `static/img/favicon-16.png`
- `static/img/favicon-32.png`
- `static/img/favicon-256.png`
- `static/img/favicon.ico`
- `static/manifest.webmanifest`
- `templates/base.html`
- `service-worker.js`

Observação: se o celular já tiver o app instalado, remova o atalho/app antigo e instale novamente para o novo ícone aparecer. Em alguns aparelhos o cache do navegador pode demorar um pouco para atualizar.
