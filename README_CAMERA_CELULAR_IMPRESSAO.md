# Impressão rápida com leitura pela câmera do celular

Foi adicionada leitura por câmera na tela **Impressão rápida**.

## Onde funciona

Na busca de produto do estoque existe o botão **📷 Ler câmera**. Ao tocar nele pelo celular, o sistema abre a câmera, lê código de barras ou QR Code e preenche automaticamente o campo de busca.

Também foram adicionados botões de câmera nos campos:

- **Código**
- **Etiqueta**

## Como usar

1. Abra o sistema pelo celular.
2. Entre em **Impressão rápida**.
3. Toque em **📷 Ler câmera** no campo de busca.
4. Aponte para o código de barras ou QR Code.
5. Quando a leitura for concluída, o sistema procura o produto no estoque automaticamente.

## Observação técnica

O acesso à câmera depende do navegador. Em geral funciona melhor no Chrome/Edge atualizado. Alguns navegadores exigem HTTPS ou acesso via `localhost` para liberar a câmera.
