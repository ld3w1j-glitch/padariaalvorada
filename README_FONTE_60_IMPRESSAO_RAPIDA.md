# Ajuste de fonte 60 na Impressão rápida

Nesta versão, os campos preenchidos na planilha de impressão rápida passam a usar fonte padrão tamanho 60.

Campos ajustados na Base.xlsx gerada:

- Produto
- Peso / Embalagem
- Data de produção
- Validade
- Etiqueta
- Quantidade de pacotes
- Código

Também foi ajustada a prévia visual da etiqueta no sistema para representar melhor a fonte grande antes de imprimir.
