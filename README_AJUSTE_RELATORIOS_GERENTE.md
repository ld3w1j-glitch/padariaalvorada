# Ajuste de acesso aos Relatórios

Correção aplicada: a tela de Relatórios não fica mais limitada a Admin/Balanço.

Agora a regra correta é:

- Se o usuário tiver a permissão manual `Relatórios`, ele acessa a tela de relatórios.
- Os cargos `Conferente` e `Separador` continuam bloqueados obrigatoriamente.
- Áreas sensíveis continuam exclusivas do cargo `Admin`.

Observação: se um usuário Gerente, Supervisor, Desenvolvedor, Estoque, Balanço ou Visualizador não acessar Relatórios, confira em Usuários > Editar se a permissão `Relatórios` está marcada.
