# Impressão rápida com prévia e QR Code

## O que foi adicionado

- A tela **Impressão rápida** agora possui uma área de **prévia antes de imprimir**.
- A prévia atualiza conforme os campos são editados.
- Foram adicionados campos para ajustar o tamanho visual da etiqueta:
  - largura em cm
  - altura em cm
- O botão **Atualizar prévia** permite conferir os dados sem baixar nem imprimir.
- O campo **Etiqueta** agora pode ser usado de duas formas:
  - texto normal
  - QR Code

## QR Code

Quando a opção **QR Code** estiver marcada, o Excel gerado coloca um QR Code no espaço da etiqueta.
Ao ler o QR Code no celular, serão exibidas as informações do produto:

- Produto
- Código
- Peso/embalagem
- Validade
- Etiqueta

## Observação sobre tamanho

A prévia mostra o tamanho aproximado na tela. A impressão real depende da impressora, papel, margem e configuração do Excel/Windows.
