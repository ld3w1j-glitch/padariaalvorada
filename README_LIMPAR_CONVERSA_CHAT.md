# Limpar conversa no chat

Foi adicionada a opção **Limpar conversa** dentro da tela de Chat/Tarefas.

## Como funciona

1. Abra **Chat/Tarefas**.
2. Selecione uma conversa ou grupo.
3. Clique no botão **Limpar** no topo do chat.
4. Confirme a ação.

A limpeza apaga as mensagens daquela conversa, mas mantém o chat/grupo criado para continuar usando depois.

## Arquivos anexados

Se houver arquivos temporários pendentes de confirmação, eles também são removidos da pasta temporária para não deixar lixo no sistema.

## Auditoria

A ação fica registrada na auditoria como `limpar_conversa_chat`, com quantidade de mensagens apagadas.
